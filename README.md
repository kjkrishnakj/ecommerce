# 🛒 AmiKart – E-commerce Platform  

AmiKart is a full-featured e-commerce platform for buying smartphones, built using **Next.js, MERN stack, and MongoDB**, and deployed on **Vercel**.  
It provides a seamless shopping experience with features like product browsing, cart management, checkout, and secure payments.  

---

## 🚀 Features  
- 📱 Browse a wide range of smartphones  
- 🛍️ Add/remove items from the cart  
- 🔐 User authentication & account management  
- 💳 Checkout with integrated payment gateway  
- 📦 Order tracking & history  
- ⚡ Deployed on Vercel with a responsive UI  

---

👉 [AmiKart Website](https://ecommerce-eta-amber.vercel.app/)

## 🛠️ Tech Stack  
- **Frontend:** Next.js, React, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB (Mongoose)  
- **Authentication:** JWT-based auth  
- **Payments:** Stripe / Google Pay integration  
- **Deployment:** Vercel
